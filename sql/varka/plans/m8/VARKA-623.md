## 2. Why `factorial` is unfused

`Factorial` takes an `INT` and returns a `BIGINT`: the product for 0 to 20, and `NULL` for any
other value, in every ANSI mode (`Factorial` in `mathExpressions.scala`: "If the value not in
the range of [0, 20], it still will be null"). A table of 21 entries serves it, as row 344's
plan says. No compiler family matches the class, so `VarkaNodeCompiler.fallback` declines it as
an "unsupported expression":
