# The curated half of the census (dev/varka_census.py, m8/PLAN.md 2.1). Edit this file, then
# rerun the script; census.tsv is generated from it and from FunctionRegistry.scala.
#
# [registered]: one registered name a line,
#   name | types it admits in the set | result | types fused today | need | rows | note
# [implicit]: operators with no registry entry of their own, built by the parser, by type
# coercion or by the analyzer and the optimizer,
#   name | class | family | types | result | fused today | need | rows | note
#
# Types are bool byte short int bigint float double dec date ntz time ym dt, or a group:
# (dec is DECIMAL up to precision 38: an unscaled long to 18, a 128-bit lane pair above)
# ("legal" for a cast alias: the sources Cast allows, computed by the script)
# INTEGRAL, FLOAT, NUM (integral, floating and decimal), IVL (ym, dt), ALL. "same" as a result
# maps each type to itself. A type marked ! is declined by the owner's decision (decimal division,
# 14 October 2026): it leaves the entry's types and is recorded in the census's reason column.
# A DECIMAL(p, s) with s < 0 (allowed only under spark.sql.legacy.allowNegativeScaleOfDecimal) is
# declined by the compiler for every entry below and is not a type of its own here (m8/PLAN.md 2.8).
# A fused type marked ~ is fused in a coverage row whose operand of
# that type is derived (a literal or another expression's result), and its note quotes that row.
# A fused type needs a coverage row whose node of the entry's class takes that type.
# A need is the hardest work left once the lanes the row names exist: done; plumbing (an arm
# and IR on the lanes); semantics (Spark's overflow, NaN, rounding or scale rules); ulp (the math
# family: fused within a bound stated per function and host library, under row 345's contract and
# its configuration, the owner's decision of 14 October 2026; since 30 October 2026, by the owner's
# word, exact by default and the bound only in that opt-in mode, VARKA-345.md 2.1); hard (no exact
# construction known:
# declined unless one is found - empty since 14 October 2026, when the reading of the papers gave
# every former hard entry its construction, m8/PLAN.md 2.7). Rows are milestone 8's task numbers (m8/PLAN.md 3).
