# Varka Task 2 - `DateVectorOps` SIMD kernels

**Status: IN PROGRESS.** See `PLAN_MILESTONE_1.md` for the high-level MVP
plan. JMH benchmarking is a **follow-up** to this task (not included here).

## 1. Goal

Pure-Java SIMD kernels for the Date/Time MVP - `vectorAddDays`,
`vectorSubDays`, `vectorDateDiff` - over Arrow date (int32 days since epoch)
data plus bit-packed validity, using `jdk.incubator.vector.IntVector`.
Kernels operate on raw addresses (`long`), so generated bytecode can call them
via `invokestatic` with a primitive stack (Task 4). Correctness is established
by differential unit tests against Arrow's own accessors and a scalar
reference.

## 3. API (argument order is the `invokestatic` stack order for Task 4)

```java
package org.apache.spark.sql.varka.vector;

public final class DateVectorOps {
  // dst[i] = src[i] + daysOffset; dst null iff src null.
  public static void vectorAddDays(long srcData, long srcValidity, int srcNullCount,
      long dstData, long dstValidity, int length, int daysOffset);

  // dst[i] = src[i] - daysOffset; delegates to vectorAddDays with -daysOffset.
  public static void vectorSubDays(long srcData, long srcValidity, int srcNullCount,
      long dstData, long dstValidity, int length, int daysOffset);

  // dst[i] = a[i] - b[i]; dst null iff a or b null (DATEDIFF).
  public static void vectorDateDiff(long dataA, long validityA, int nullCountA,
      long dataB, long validityB, int nullCountB,
      long dstData, long dstValidity, int length);
}
```

Semantics and contract:

- `srcData`/`dstData` point to `length * 4` bytes of int32 day values.
- `srcValidity` points to `(length + 7) / 8` bytes, bit-packed, bit set =
  valid (Arrow layout). It is dereferenced **only** when
  `0 < srcNullCount < length`; callers whose column is all-null
  (`srcNullCount == length`) or null-free (`srcNullCount == 0`) may pass `0L`
  (matches `VarkaMorsel.DateMorsel.validity() == null` for all-null columns).
- `dstValidity` is always required (non-zero); the kernel writes the output
  null bits. Rows beyond `length` in the final partial byte are cleared.
- Values for null output rows in `dstData` are undefined.
- Int32 arithmetic wraps on overflow, matching Spark's `DateAdd` semantics.
- Endianness is `ByteOrder.LITTLE_ENDIAN` (Arrow's in-memory layout).

## 4. Algorithm (per kernel)

1. Wrap segments: `MemorySegment.ofAddress(addr).reinterpret(len * 4L)` for
   data, `.reinterpret((len + 7) / 8)` for validity.
2. Fast paths: `length == 0` -> return; `nullCount == length` -> zero the dst
   validity bytes and return (never deref validity); `nullCount == 0` ->
   `VectorMask.maskAll(SPECIES)`.
3. Zero the dst validity bytes up front so the vector loop and scalar tail can
   just OR bits in (avoids cross-chunk long writes clearing sibling rows).
4. Vector loop over chunks at `i` (`SPECIES = IntVector.SPECIES_PREFERRED`),
   guarded by `i / 8 + 8 <= (length + 7) / 8` (last-chunk long-read safety):
   - `long bits = validity.get(ValueLayout.JAVA_LONG, i / 8L)`
   - `VectorMask<Integer> mask = VectorMask.fromLong(SPECIES, bits)` (or
     `maskAll` when `nullCount == 0`)
   - masked `IntVector.fromMemorySegment(SPECIES, src, (long) i * 4,
     LITTLE_ENDIAN, mask)` -> `add(offsetVec, mask)` / `sub` ->
     masked `intoMemorySegment(dst, (long) i * 4, LITTLE_ENDIAN, mask)`
   - OR `mask.toLong()` into `dstValidity` at `i / 8L`
5. `vectorDateDiff`: build `maskA` and `maskB` independently (each `maskAll`
   when its `nullCount == 0`), combine with `maskA.and(maskB)`; two masked
   loads, `va.sub(vb, mask)`, one masked store.
6. Scalar tail from the first row the guard excludes (and the
   non-multiple-of-8 remainder): per-row validity read (bit test) and dst
   validity read-modify-write; skip validity reads when `nullCount == 0`.

## 5. `DateVectorOpsTest.java` - differential test matrix

Sources are `DateDayVector`s built under an Arrow `RootAllocator` (reusing the
`VarkaMorsel` mapping); destinations are native `MemorySegment`s from a
confined `Arena`. Expected values are computed two ways: Arrow's own
`get(i)`/`isNull(i)` oracle and a scalar reference loop.

- Lengths spanning species boundaries and the validity guard path:
  `1, 7, 8, 9, 15, 16, 17, 31, 32, 33, 63, 64, 65, 100, 1000, 100_000`.
- Null patterns: no-null (`nullCount == 0`, validity address may be `0L`),
  all-null (`nullCount == length`, never derefs validity, dst validity
  all-zero), alternating, sparse (every 7th), dense, first-row-null,
  last-row-null.
- Offsets: `0`, negative, large positive/negative; wraparound parity near
  `Integer.MAX_VALUE`.
- `vectorSubDays`: same matrix via negation.
- `vectorDateDiff`: differing null patterns between A and B, both no-null,
  one all-null, both all-null (AND semantics: null iff either is null).
